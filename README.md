## Project Overview

**Stellar DeFi Savings Vault** is a simple savings vault demo built for Stellar Level 3.

The app allows users to simulate XLM savings deposits, track deposit history, monitor progress toward a savings goal, and view tested smart contract logic. The Soroban contract stores user deposit balances, total deposited amount, deposit count, and deposit records.

This project is designed as a beginner-friendly DeFi savings vault prototype on Stellar Testnet.
